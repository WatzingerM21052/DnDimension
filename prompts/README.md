# DnDimension Prompts

| Prompt | Status | Verwendung |
|---|---|---|
| [Solo AI-DM Master Prompt v2](dnd-solo-ai-dm-master-prompt-v2.md) | Stable Candidate | Empfohlener vollständiger Solo-Modus |
| [Group AI-DM Overlay](dnd-group-ai-dm-master-prompt-experimental.md) | Experimental | Zusatz für mehrere menschliche Spieler |
| [AI-DM System Prompt v1](dnd-ai-dm-system-prompt.md) | Legacy | Kurze, ältere Standalone-Fassung |

Der Solo-Prompt ist die maßgebliche Fassung. Für einen Gruppenversuch wird zuerst der Solo-Prompt und unmittelbar danach das Gruppen-Overlay eingefügt. Eine KI kann lokale Dateien nur verwenden, wenn die jeweilige Chat- oder Agentenumgebung tatsächlich Zugriff darauf hat.

Ausführliche Verwendung: [AI-DM Prompt-Anleitung](../docs/guides/ai-dm-prompt-usage.md).
