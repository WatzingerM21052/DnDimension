# Projektmarketing

## Positionierung

**DnDimension hilft Spielern und Dungeon Mastern, D&D 5e regelkonform und verständlich zu spielen, ohne das Regelwerk auswendig kennen oder mehrere Werkzeuge parallel pflegen zu müssen.**

## Kernbotschaften nach Phase

| Phase | Botschaft |
|---|---|
| v0.5 | Charakter und Kampagne erstmals in einer lokalen Alpha verbunden |
| v0.7 | Zusammenhängende Single-User-App ohne Account- oder KI-Abhängigkeit |
| v1.0 | Player- und DM-Werkzeuge ohne Accountzwang und ohne KI-Abhängigkeit |
| v1.2-v1.5 | Vom optionalen Account über Freigaben bis zum stabilen Gruppenspiel |
| v2.0 | Ein immersiver, visuell konsistenter Spieltisch statt digitaler Papierformulare |
| v3.0-v3.5 | Vom kontrollierten DM-Copilot zum quellengebundenen Solo-KI-DM |

## Kanäle

- GitHub für transparente Entwicklung, Issues und Releases;
- kurze Entwicklungsberichte mit Screenshots oder Demos;
- geschlossene Playtests mit klarer Feedbackstruktur;
- später passende D&D-/TTRPG-Communities unter Beachtung ihrer Regeln;
- keine Bewerbung proprietärer Downloads oder nicht lizenzierter Inhalte.

## Launch-Artefakte je Release

- verständliche Release Notes;
- kurze Demo des zentralen Nutzerflusses;
- bekannte Einschränkungen;
- Datenschutz-/Datenhinweis;
- Feedback-Link mit Version und Reproduktionsschritten.

## Erfolgsmessung

- Aktivierungsrate und Abschluss zentraler Flows;
- wiederkehrende Nutzung über mehrere Sitzungen;
- qualitative Entlastung für DMs;
- Regel- und Datenfehler pro Testsession;
- v3+: Kosten und Quellenfehler pro KI-Sitzung.
