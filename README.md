# DnDimension

Eine Web-App, um D&D 5e zu spielen — solo mit KI-DM, in der Gruppe mit KI-DM, oder in der Gruppe mit menschlichem DM. Ziel: das volle 5e-Regelgerüst, aber zugänglich für Leute, die die Regeln nicht auswendig kennen.

**Status:** Planungsphase — noch keine Implementierung.
